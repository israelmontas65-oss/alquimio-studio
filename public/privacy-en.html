01 Identity, Ownership & Scope

This document establishes the binding Security and Privacy Policy for the web platform and mobile application Alquimia Studio (hereinafter, "the Application", "Alquimia Studio" or "our services"), publicly hosted at https://alquimia-studio.pages.dev.

The sole ownership, intellectual property, and technical development of Alquimia Studio legally belong to Israel Montás.

Alquimia Studio is a high-performance creator and enterprise tool designed for drafting AI-optimized captions and batch-publishing multimedia (vertical video, TikToks, Reels, YouTube Shorts, photos) directly to authorized accounts via official platform APIs.

02 Zero Commercialization & Data Minimization Principle

🔒 Non-Negotiable Privacy Commitment: Alquimia Studio DOES NOT sell, rent, lease, trade, or transfer personal data, account identifiers, or user credentials to advertisers, data brokers, or any third party under any circumstances.

We follow the strict principle of Data Minimization (Privacy by Design). We only process technical data strictly necessary to facilitate authorized publishing requested by the user:

  • Public Account Identifiers: Platform-assigned anonymous IDs (e.g., TikTok open_id, Facebook page_id, YouTube channel_id), display names, and public avatars strictly to display active connection status in the dashboard.
  • Temporary OAuth Access Tokens: Cryptographic keys granted by the user to execute publishing requests on their behalf via official endpoints.
  • Selected Media for Publication: Video/image files, title, caption, and hashtags provided directly by the user in the editor.

Specific Compliance with Meta's WhatsApp Business Messaging Policy

In strict accordance with Meta's WhatsApp Business Messaging Policy, Alquimia Studio guarantees:

  • Explicit Prior Consent (Opt-In): Alquimia Studio only facilitates messaging to recipients who have provided clear, voluntary, and verifiable prior consent (opt-in). Unsolicited messages, purchased lists, and spam are strictly prohibited.
  • 24-Hour Customer Service Window: Free-form messaging and direct conversations are restricted exclusively to the 24-hour window following the last user-initiated inbound message.
  • Meta-Approved Message Templates: For any notification sent outside the 24-hour window, Alquimia Studio utilizes exclusively pre-approved Meta Message Templates under approved categories (Utility, Authentication, or Marketing).
  • Immediate Opt-Out Handling: Any user request to unsubscribe or stop communication (e.g., replying "STOP" or "CANCEL") is honored immediately, halting any subsequent messaging.

Google API Services User Data Policy Compliance

Alquimia Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is never used for general AI training or transferred to third parties.

TikTok Developer Terms of Service Compliance

Our integration with TikTok for Developers strictly adheres to API v2 standards, protecting credentials through PKCE (RFC 7636) and respecting creator privacy choices.

04 Security, Cryptography & Token Protection

Alquimia Studio implements enterprise-grade defense mechanisms to protect all data in transit and at rest:

  • Mandatory In-Transit Encryption (TLS 1.3 / HTTPS): All communications between the client device, Cloudflare Pages servers, and external APIs are enforced via TLS 1.3 encryption.
  • Server-Side Secret Storage: Developer secrets (TIKTOK_CLIENT_SECRET, Meta App Secrets, Google Client Secrets) reside encrypted in Cloudflare Pages environment variables. No secrets are ever exposed to client-side code.
  • Anti-CSRF Cryptographic Protection (HMAC-SHA256): Every authorization request produces a cryptographically signed state parameter with a 10-minute expiration window (TTL) to prevent Cross-Site Request Forgery.
  • Secure Session Storage: Web sessions utilize strict cookie attributes: HttpOnly, SameSite=Lax, and Secure. Mobile native apps employ hardware-backed secure enclaves (iOS Keychain and Android Keystore with AES-256-GCM).

05 Media & Video Processing (Zero Permanent Storage)

⚡ Ephemeral Processing Notice: Videos and images uploaded to Alquimia Studio are processed purely in-transit to transmit them to your target social media destinations. Alquimia Studio DOES NOT retain copies of your videos on its servers once publication is confirmed.

When you initiate a batch publish, the media file is streamed directly from your device to the authorized endpoints of TikTok, YouTube, or Meta. Once the social network confirms successful publication, all temporary in-memory buffers are immediately erased.

06 Access Revocation & Session Deletion

Users retain total and irreversible control over their connected accounts:

  • One-Click Disconnect: From the platform settings modal, users can click "Disconnect account & revoke access".
  • Remote API Revocation: Alquimia Studio immediately sends an official revocation request (e.g., to https://open.tiktokapis.com/v2/oauth/revoke/), instantly invalidating tokens on the social platform's servers.
  • Local Storage Cleanup: All local tokens, session cookies, and user IDs are wiped from local storage and memory instantly.

08 User Rights (GDPR, CCPA & Global Protections)
