Guía de Integración y Configuración

Instrucciones oficiales para conectar portales de desarrolladores con Alquimia Studio.

01 TikTok for Developers (Login Kit & Content Posting)

Sigue estos pasos en el portal de TikTok Developers (developers.tiktok.com):

  1. Crear o Seleccionar App: Ve a Manage Apps y selecciona tu aplicación Alquimia.
  2. Agregar Productos: Agrega Login Kit y Content Posting API v2.
  3. Verificación de Dominio: En la casilla de dominio, coloca exactamente: 
    alquimia-studio.pages.dev
    (Sin https:// ni barra diagonal al final).
  4. Redirect URIs: Registra las siguientes URLs autorizadas:
    Entorno Redirect URI Exacto
    Producción Web / PWA https://alquimia-studio.pages.dev/oauth/tiktok
    Desarrollo Local http://localhost:8081/oauth/tiktok
    App Nativa Móvil alquimia://oauth/tiktok
  5. Scopes (Permisos): Selecciona user.info.basic, user.info.profile, video.upload y video.publish.
  6. Credenciales: Copia tu Client Key y Client Secret.
Ir a TikTok for Developers →

02 Configuración en Cloudflare Pages

Las credenciales de servidor deben guardarse de forma protegida en el panel de Cloudflare:

  1. Ingresa a dash.cloudflare.com > Workers & Pages.
  2. Selecciona el proyecto alquimia-studio.
  3. Ve a Settings > Environment variables.
  4. Agrega las variables para Production y Preview:
    Nombre de la Variable Valor Requerido
    TIKTOK_CLIENT_KEY Tu Client Key de TikTok Developers
    TIKTOK_CLIENT_SECRET Tu Client Secret de TikTok Developers
  5. Guarda los cambios y haz un nuevo despliegue si es necesario.

03 Meta for Developers (Facebook & Instagram)

Para la vinculación oficial con páginas de Facebook y cuentas de Instagram Business:

  • Redirect URI Oficial: https://alquimia-studio.pages.dev/oauth/meta
  • Deep Link Nativo: alquimia://oauth/meta
  • URL de Eliminación de Datos (Data Deletion Callback): 
    https://alquimia-studio.pages.dev/api/meta/data-deletion
  • URL de Comprobante / Instrucciones: 
    https://alquimia-studio.pages.dev/eliminar-datos.html
Ir a Meta for Developers →

04 Google Cloud Console (YouTube Data API v3)

  • Redirect URI Web: https://alquimia-studio.pages.dev/oauth/youtube
  • Redirect URI Móvil: alquimia://oauth/youtube
  • Scopes: https://www.googleapis.com/auth/youtube.upload y https://www.googleapis.com/auth/youtube.readonly.
